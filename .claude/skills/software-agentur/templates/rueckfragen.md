# Rückfragen

Jeder Agent trägt hier eigene Fragen ein und beantwortet die an ihn gerichteten.
Fremde Einträge werden nicht verändert — nur der Antwortblock wird ergänzt.

Regel: Nach **zwei** Runden ohne Klärung entscheidet der `tech-lead`.
